# Prompts para Leonardo AI

## Reglas de consistencia

- Usar el mismo modelo y la misma imagen de referencia para una serie de salas.
- Generar fondos en 16:9, preferentemente 1920×1080.
- Generar objetos en 1:1, preferentemente 1024×1024.
- No incluir texto legible, botones, flechas, inventario, logotipos ni hotspots en las imágenes.
- No incluir niebla, horror, sombras amenazantes, sangre, monstruos ni elementos paranormales.
- Mantener una aventura espacial seria y educativa para jugadores de 10 a 19 años.
- Dejar zonas despejadas para colocar interacción en Phaser.

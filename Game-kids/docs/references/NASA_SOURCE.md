# Referencia técnica NASA del mapa

## Fuente principal

- **Documento:** `space-shuttle-orbiter-drawings.pdf`
- **Sujeto documentado:** Space Transportation System Orbiter Discovery (OV-103)
- **Fuente institucional:** NASA / Historic American Engineering Record
- **Referencia web oficial:** https://www.nasa.gov/gallery/space-shuttle-technical-diagrams/

## Regla de diseño

El mapa de **Alone in the Space** debe derivarse de los planos y diagramas técnicos compartidos. Las escenas deben conservar, en lo posible, la relación espacial y la nomenclatura de las zonas documentadas: bahía de carga útil, cabina de tripulación, cubierta de vuelo, middeck, accesos entre cubiertas, escotilla lateral, acceso a esclusa, aviónica, potencia, ECLSS, OMS y RCS.

El juego puede simplificar distancias, aumentar áreas interactivas y añadir daños, objetos, bloqueos o registros ficticios para crear acertijos. Esas adiciones se documentarán como ficción narrativa y no se presentarán como instalaciones reales de NASA.

## Trazabilidad requerida

Cada escena o mapa nuevo debe registrar en `docs/map-traceability.md`:

1. La zona representada.
2. La página o lámina del PDF utilizada.
3. La vista técnica utilizada: planta, elevación, sección o isométrico.
4. Los elementos conservados.
5. Las simplificaciones o adiciones ficticias.

La fuente se conserva dentro del repositorio para que el equipo pueda revisar la referencia sin depender únicamente de una URL externa.
